bcollie-modbot Commands

Last updated: July 18, 2026

If you want to summon me in a subreddit to which I am installed, create a comment which includes one of my commands. The full command list is below.

I will also respond automatically to posts which might be asking a question like "what breed is this dog?" with a similar response to my !id response.

If you have any feedback about the response for a specific command, send it to the moderators of the subreddit the bot responded in via Modmail.

More commands may be added later. Suggestions can be sent by Modmail to the /r/BorderCollie moderators.

If you are the moderator of another subreddit and would like to use or adapt bcollie-modbot for your community, please reach out to /u/HezzaE. The bot can be installed to any subreddit, and the responses can be customised to suit your community's needs.

Appearance and Breed ID

Command

!id!appearance!appearances

Response

bcollie-modbot will respond with some information on visual breed identification and appearance, configured by the moderators of the subreddit it is installed in.

Name Suggestions

Command

!names!girlnames!boynames

Response

bcollie-modbot will reply with a randomised list of names drawn from a pool of dog names. The names will range from very typical and common dog names to very silly ones.

If you specify !girlnames or !boynames, some more traditionally feminine or masculine names will be added to the pool along with the more gender-neutral options.

You can also add a number after this command to specify how many names you'd like, for example !names 20.

If you'd like to add some name suggestions to the pool, or you think one or more names might be miscategorised, let the /r/BorderCollie moderators know.

Health, Injury, and Illness

Command

!vet!emergency!health!injury!illness

Response

bcollie-modbot will respond with some information about what to do if your dog is sick or injured, and how to find a veterinarian. The exact response is configured by the moderators of the subreddit it is installed in.
